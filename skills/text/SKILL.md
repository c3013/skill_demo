# Text Skill

## When to Use

- User needs to convert text to upper or lower case
- User wants to count the number of words in a passage
- User asks to reverse a string
- User wants all email addresses extracted from a block of text

## Available Tools

- `to_uppercase` – convert a string to uppercase
- `to_lowercase` – convert a string to lowercase
- `count_words` – count the number of words in a string
- `reverse_text` – reverse the characters in a string
- `extract_emails` – extract all email addresses found in a string

## Notes

All tools operate on plain-text strings and have no external dependencies.
